# @project/functions-sdk

The generated TypeScript client for the Studio backend in `packages/functions`. The UI imports it for typed RPC and React Query hooks.

- `src/pikku/` is generated by `pikku all` (paths set under `clientFiles` in the root `pikku.config.json`): the fetch client, RPC wirings, the React Query hooks (`api.gen`), realtime and the RPC/HTTP type maps. Do not edit these by hand.
- `src/types.ts` is the hand-written part.
- Exports: `./types`, `./pikku/api.gen`, `./pikku/pikku-fetch.gen`, `./pikku/pikku-rpc.gen`, `./pikku/rpc-map.gen`, `./pikku/http-map.gen`.
- `@pikkustudio/blocks` imports `@project/functions-sdk/pikku/api.gen`; see `docs/os-sdk-contract.md`.
