# Searching the Spindle library

1. Start with the whole library. Ask the question in plain words.
2. If the answer is off topic, repeat the search inside the most relevant collection.
3. For a single word or name, use plain search instead of asking a question.
4. Quote the file and its page, frame or time so the person can open it.
5. If nothing matches, say "not in your files". Do not guess.
