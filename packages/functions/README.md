# @project/functions

The Studio backend, written as Pikku functions. It is the app's server: the Studio API, auth, services and the addons it hosts.

- `src/addons/` wires the addons (`@pikkustudio/addon-studio`, `addon-inbox`, `addon-review`); `src/functions/` holds the app's own functions (health, project run and flow, sleep, vault, registry, headless runs, translate and more).
- HTTP routes are in `src/studio.http.ts` and `src/oauth.http.ts`; middleware in `src/middleware/`, permissions in `src/permissions/`.
- `src/services.ts` builds the singleton and per-request services (secrets, variables, audit, email, vault connection, the Studio instance from `src/lib/studio.ts`).
- `src/lib/` has helpers; `src/lib/addons-project.ts` copies `templates/addons-project` into the user's Studio home on first use.
- `.pikku/` is generated by `pikku all` from the repo root (see the root `prebuild` script); the generated client goes to `packages/functions-sdk`.
- `bun run test` runs `bun test src`; `bun run tsc` type-checks (there is no tsconfig here, the root one is used).
